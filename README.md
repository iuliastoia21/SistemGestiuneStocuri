# 📦 Sistem de Gestiune a Stocurilor în Microsoft Excel

Un proiect realizat în **Microsoft Excel** pentru gestionarea stocurilor, urmărirea intrărilor și ieșirilor de produse și vizualizarea datelor printr-un dashboard interactiv.

## 📋 Funcționalități

* Gestionarea produselor și a informațiilor asociate
* Evidența intrărilor în stoc
* Evidența ieșirilor din stoc
* Calcul automat al stocului disponibil
* Calculul valorii stocului pentru fiecare produs
* Dashboard cu indicatori principali (KPI)
* Grafice pentru analiza stocurilor și a mișcării produselor

## 📂 Structura proiectului

* **Produse** – lista produselor și informațiile de bază
* **Intrări** – înregistrarea produselor intrate în stoc
* **Ieșiri** – înregistrarea produselor ieșite din stoc
* **Inventar** – calculul stocului disponibil și al valorii stocului
* **Dashboard** – indicatori și grafice pentru analiza datelor

## 📊 Dashboard

Dashboard-ul include:

* Valoarea stocului pe produs
* Stoc disponibil pe produs
* Comparație între intrări și ieșiri
* Distribuția produselor

## 🛠️ Funcții Excel utilizate

* `SUMIF()`
* `XLOOKUP()`
* `IF()`
* Referințe între foi
* Tabele Excel (Excel Tables)

## 📈 Elemente de vizualizare

* Clustered Column Chart
* Clustered Bar Chart
* Pie Chart
* Carduri KPI pentru indicatorii principali

## 🎯 Scopul proiectului

Acest proiect demonstrează utilizarea funcțiilor și instrumentelor din Microsoft Excel pentru gestionarea stocurilor și realizarea unui dashboard de analiză a datelor.
